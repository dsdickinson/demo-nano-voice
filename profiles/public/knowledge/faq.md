# Edge Assistant FAQ

## Is internet connection required?
No. All components of Nano-Voice including Speech-to-Text, LLM inference, local vector search, and neural text-to-speech run offline on local hardware.

## What persona does the assistant use?
The default public persona is Nova: an articulate, concise edge AI assistant with a natural female speaking tone.

## How does RAG enhance response quality?
Retrieval-Augmented Generation searches local markdown and text documents for relevant information before the language model generates an answer, minimizing hallucinations and enabling instant memory updates.
